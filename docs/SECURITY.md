# الأمان

- لا حسابات ولا رموز يدوية؛ دعوة لمرة واحدة وقصيرة الصلاحية.
- تشفير الاتصال (TLS) وتشفير من طرف إلى طرف للمحتوى.
- الخادم لا يرى الملفات ولا مفاتيح التشفير.
- لا وصول للوسائط قبل موافقة صريحة من المستخدم على الهاتف.
- زر «إلغاء الوصول» في الهاتف يقطع الجلسة ويُبطل المفاتيح فورًا.
- المستودع عام: لا تُرفع مفاتيح التوقيع (.jks) ولا ملفات .env ولا كلمات سر.
